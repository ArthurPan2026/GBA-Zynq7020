# 2026-11-22 1080p30 动态切换验证记录

## 结果

修复后，Zybo Z7-20 可在 `720p60` 与 `1080p30` 之间双向切换。板端状态为 `pending=0`、`error=0`，HDMI（High-Definition Multimedia Interface，高清多媒体接口）时钟锁定、VSYNC（vertical synchronization，垂直同步）和 pixel clock 均正常。

采集卡分别录到 `1280×720`、约 `60 帧/秒` 和 `1920×1080`、约 `30 帧/秒`。稳定模式画面正常。切换期间的采集视频出现约 `1.1～1.27 s` 黑帧，之后恢复稳定画面。

## 故障定位

旧版实板请求 `1080p30` 后，固件回退到 `480p60` 并报告 `error=13`。FPGA 状态寄存器保留的失败阶段为 `5`（`WAIT_CONFIG`），`config_ready=0`，同步 VSYNC 为 `1`。时钟和同步已工作，等待 scaler 配置确认超时。

`video_mode_config_ready` 要求 scaler 空闲、配置队列清空、几何合法，且活动输出尺寸匹配请求。模式切换会暂停 AXI（Advanced eXtensible Interface，高级可扩展接口）视频输入，但 scaler 复位只受 `abort_stream` 控制。若暂停发生在帧处理中，scaler 会保持 busy；没有新像素完成该帧，配置确认就无法通过。状态寄存器的 `VIDEO_BUSY` 在失败采样中为 `1`，与此根因一致。

## 代码修改

- `EmbeddedVideoIP/ip/video_pipeline_1_0/hdl/video_pipeline_v1_0.sv`：模式控制器保持 pixel reset 时，同时复位 scaler 和视频流状态，使 scaler 回到 `WAIT_SOF`。
- `EmbeddedVideoIP/ip_repo/panfpga/embedded_video_ip/src/video_pipeline_v1_0.sv` 和 GBA（Game Boy Advance）项目的 `ip-repo/embedded-video-ip/ip_repo/panfpga/embedded_video_ip/src/video_pipeline_v1_0.sv`：与 canonical RTL（Register-Transfer Level，寄存器传输级）同步。
- GBA 项目的 `scripts/vivado/build_bitstream.tcl`：每次构建刷新当前 IP（Intellectual Property，知识产权核）catalog 和 BD 输出，并应用 `evip_bd_apply_z7_clock_constraints`，避免 Clock Wizard 层级 XDC（Xilinx Design Constraints，Xilinx 约束文件）重新启用主时钟。
- `fpga-project.toml`：将 `embedded_video_ip_bd.tcl` 加入硬件阶段输入指纹。
- `PACKAGE_METADATA.json`、`RELEASE-METADATA.json`：按当前 canonical 和 vendored 内容重新生成或核对哈希。
